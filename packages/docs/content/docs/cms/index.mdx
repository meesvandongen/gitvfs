---
title: Getting started
description: A Git-backed CMS for markdown, JSON and YAML content, with forms and a live preview.
---

`gitvfs-cms` manages content that lives as files in a Git repository: blog posts with YAML
frontmatter, documentation pages, JSON or YAML settings. You describe the content with
[zod](https://zod.dev) schemas, and get a typed API plus an editor whose forms are generated by
[AutoForm](https://autoform.vantezzen.io/). Every save is a commit made through
[gitvfs](/docs/gitvfs).

## Install

```sh
pnpm add gitvfs gitvfs-cms zod
# for the editor UI
pnpm add react react-dom react-hook-form @hookform/resolvers
```

## Describe your content

```ts
import { z } from 'zod'
import { defineCollection, defineSingleton, field, markdown } from 'gitvfs-cms'

export const posts = defineCollection({
  name: 'posts',
  label: 'Posts',
  folder: 'content/posts',
  schema: z.object({
    title: z.string().min(1),
    date: z.coerce.date().optional().check(field({ label: 'Publish date' })),
    tags: z.array(z.string()).default([]),
    draft: z.boolean().default(false),
    body: z.string().check(markdown()).default(''),
  }),
})

export const site = defineSingleton({
  name: 'site',
  label: 'Site settings',
  path: 'data/site.json',
  schema: z.object({ title: z.string(), description: z.string().optional() }),
})
```

## Mount the editor

```tsx
import { GitFS } from 'gitvfs'
import { github } from 'gitvfs/providers/github'
import { createCms } from 'gitvfs-cms'
import { CmsApp } from 'gitvfs-cms/react'
import 'gitvfs-cms/styles.css'

const cms = createCms({
  fs: new GitFS({ provider: github({ owner: 'acme', repo: 'site', token }), branch: 'main' }),
  collections: [posts],
  singletons: [site],
})

export function Admin() {
  return <CmsApp cms={cms} title="Acme content" />
}
```

`CmsApp` lists your collections and singletons, shows the entries of a collection, and opens them
in a form with a live preview. Saving validates the form against the schema and commits the file.

## Or use the API

```ts
const entries = await cms.listEntries('posts') // [{ slug, path, label, data }]
const post = await cms.readEntry('posts', 'hello-world') // { data, issues, … }

await cms.saveEntry('posts', {
  slug: 'hello-world',
  previousSlug: 'hello-world',
  data: { ...post.data, title: 'Hello, world' },
})
```
